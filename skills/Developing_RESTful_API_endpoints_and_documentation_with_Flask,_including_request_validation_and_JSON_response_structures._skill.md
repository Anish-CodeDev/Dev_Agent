Use this when the user needs to build a new Flask application, add routes with request validation, generate OpenAPI/Swagger documentation, or define structured JSON response schemas. Works best with requests like 'create a Flask API for X', 'add validation to my endpoint', or 'document my Flask routes'. compatibility: runtime: Python 3.8+ dependencies: flask, flask-pydantic, flasgger env_vars: FLASK_APP --- # Flask RESTful API Development Guide This skill provides a standardized workflow for building robust, validated, and documented RESTful APIs with Flask. --- ## Prerequisites Ensure the following packages are installed to handle routing, validation, and documentation: ```bash pip install flask flask-pydantic flasgger ``` --- ## Core Concepts 1. Request Validation: Use `flask-pydantic` to enforce data types and constraints on incoming JSON bodies. 2. Documentation: Integrate `flasgger` to auto-generate Swagger UI based on docstrings and schemas. 3. Response Structure: Always wrap data in a consistent JSON envelope (e.g., {'status': 'success', 'data': ...}). --- ## Step-by-Step Instructions 1. Initialize Flask with Flasgger: Wrap the `app` in the `Swagger` object to enable the `/apidocs` endpoint. 2. Define Request Schemas: Use `pydantic.BaseModel` to define input data structures. 3. Create Validated Routes: Use the `@validate()` decorator to link pydantic models to routes. 4. Add Swagger Docstrings: Include YAML-formatted comments in route functions for endpoint documentation. --- ## Full Example ```python from flask import Flask, jsonify from flask_pydantic import validate from pydantic import BaseModel from flasgger import Swagger  app = Flask(__name__) swagger = Swagger(app)  class UserSchema(BaseModel):     username: str     age: int  @app.route('/user', methods=['POST']) @validate() def create_user(body: UserSchema):     """     Create a new user     ---     parameters:       - name: body         in: body         required: true         schema: UserSchema     responses:       200:         description: User created     """     return jsonify({'status': 'success', 'user': body.dict()}) ``` --- ## Error Handling & Edge Cases | Symptom | Likely cause | Fix | |---------|-------------|-----| | 400 Bad Request | Validation failure | Check input against Pydantic schema | | 404 Not Found | Missing route | Verify @app.route path matches request | | Swagger UI blank | Missing docstrings | Add YAML to function docstrings | --- ## Output Format Provides a Python file structure containing the Flask app, schemas, and endpoint definitions, plus instructions to access the Swagger dashboard. --- ## Test Cases ### Test Case 1 — Happy Path **Prompt:** 'Create a Flask endpoint to register a product with name and price' **Expected behaviour:** Generate code using Pydantic for validation and Flasgger for docs. **Pass criteria:** Code is runnable and Swagger UI renders the definition. ### Test Case 2 — Edge Case **Prompt:** 'Add validation to ensure product price is positive' **Expected behaviour:** Update Pydantic model with `Field(gt=0)`. **Pass criteria:** API returns 400 for negative price inputs. ### Test Case 3 — Error Recovery **Prompt:** 'My API crashes when invalid JSON is sent' **Expected behaviour:** Suggest adding an error handler for `pydantic.ValidationError`. **Pass criteria:** API returns a clean JSON error message instead of 500.
